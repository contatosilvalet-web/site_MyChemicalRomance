# ⚡ Sidebar Sticky com Scroll & Fan Made — My Chemical Romance

> **Exercício 04 — CSS Semana 04**  
> **Projeto Aceleradora Inclusiva** | Desenvolvimento Web Front-End

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades do **Projeto Aceleradora Inclusiva**, com o objetivo de praticar conceitos avançados de posicionamento em CSS — especificamente a criação de uma **barra lateral (*sidebar*) fixa que acompanha a rolagem da página** (`position: sticky`).

Para aplicar os conceitos de forma criativa e autêntica, a interface foi construída como um **site *fan made* dedicado à banda My Chemical Romance**, adotando um design editorial, minimalista e gótico/moderno.

---

## 🎯 Objetivos do Exercício

- [x] Criar uma barra lateral (*sidebar*) de navegação que permaneça visível durante a rolagem do conteúdo (`sticky`).
- [x] Desenvolver uma estrutura HTML5 semântica e organizada.
- [x] Aplicar estilização avançada em CSS3 (Flexbox/Grid, variáveis e transições).
- [x] Implementar recursos de **Acessibilidade Web (a11y)** e **Tecnologia Assistiva**.

---

## ♿ Recursos de Acessibilidade & Inclusão (DevInclui)

Alinhado aos princípios de design inclusivo, a aplicação conta com um **Painel de Acessibilidade** interativo que oferece:

- **Ajuste Dinâmico de Fonte**: Aumentar (`A+`), diminuir (`A-`) e restaurar o tamanho do texto.
- **Modos de Contraste e Cor**: Alto contraste, modo monocromático e inversão de cores.
- **Recursos Visuais**: Guia de leitura focal, cursor ampliado e tipografia otimizada para dislexia.
- **Suporte a Leitor de Tela**: Função *Text-to-Speech* integrada para leitura em voz alta.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout responsivo e efeito *sticky scroll*.
- **JavaScript (Vanilla)**: Manipulação do DOM para os recursos interativos do painel de acessibilidade.
